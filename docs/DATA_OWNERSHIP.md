# 数据归属与事实源

## PostgreSQL：业务唯一事实源

用户、身份、作品、版本、审核、商品、订单、支付、退款、权益、文件、构建任务及财务数据只能写入 PostgreSQL。任何页面展示的交易状态必须从 PostgreSQL 获取。

## D1：匿名增长辅助数据

D1 只保存许愿池和需求分析等非交易数据。每条写入必须带 `actor_id`：优先使用可信的平台用户头，否则使用 HttpOnly 匿名 Cookie。D1 数据不能决定作品权限、订单状态、余额或交付结果。

## 浏览器状态：仅界面偏好

浏览器状态只能保存导航、临时表单和界面偏好。不得作为用户资产、订单、权益、审核或余额的事实源。

## 迁移规则

- PostgreSQL 结构只通过 Alembic 迁移。
- D1 结构只通过 Drizzle Schema 和生成的 SQL 迁移。
- API 中的 `CREATE TABLE IF NOT EXISTS` 只用于本地初始化兼容，不能代替部署迁移。
- 所有数据结构变化必须同时更新数据字典和自动化测试。
