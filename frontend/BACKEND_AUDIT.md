## 运行环境

用户本次提供的密钥经 OpenAI 官方接口验证返回 `401 invalid_api_key`，已从生产环境移除，避免失败请求增加等待时间。代码不会在浏览器中读取或暴露密钥；模型接入需要有效的 OpenAI 密钥，或该密钥所属平台的 API 地址与模型名称。
