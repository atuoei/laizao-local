# 指标字典

统计使用 UTC 存储，展示层转换为 Asia/Shanghai。正式报表过滤管理员和测试账号。

| 指标 | 唯一主体 | 定义 |
|---|---|---|
| 作品浏览人数 | `user_id`，匿名时 `session_id` | 时间范围内至少浏览一次已上架作品 |
| 作品试用人数 | `user_id`，匿名时 `session_id` | 时间范围内至少打开一次试玩 |
| 创建订单人数 | `user_id` | 至少创建一笔订单 |
| 支付成功人数 | `user_id` | 至少一笔支付成功 |
| 浏览转下单 | 独立下单人数 / 独立浏览人数 | 同一统计窗口的方向性转化率 |
| 下单转支付 | 独立支付人数 / 独立下单人数 | 同一统计窗口的方向性转化率 |

匿名浏览和试玩按“会话 + 作品 + 事件类型”去重。支付、权益与退款指标必须与交易表核对，事件表只用于分析，不作为财务事实。
